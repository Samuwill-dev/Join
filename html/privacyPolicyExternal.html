2. Purpose of this application

Join is a non-commercial learning project. It is a Kanban-based task management tool created for educational purposes only. Please do not enter sensitive personal data or passwords that you use for other services.

3. Data we collect

When you use Join, we store the following data:

  • Account data: name, email address and password (on sign up)
  • Contacts you create: name, email address and phone number
  • Tasks you create: title, description, due date, priority, category, subtasks and assigned contacts

All users, including the guest login, share the same board, contacts and tasks. Content you create is therefore visible to other users of Join.

4. Hosting

This website is hosted on GitHub Pages, a service of GitHub, Inc., USA. When you visit the website, GitHub may process technical data such as your IP address in server log files. For more information, see the GitHub Privacy Statement.

5. Database

Account data, contacts and tasks are stored in the Firebase Realtime Database, a service provided by Google. The database is hosted in [REGION]. For more information, see the Firebase Privacy and Security page.

6. Session storage

To keep you logged in while you navigate between pages, Join uses the sessionStorage of your browser. This data is deleted automatically when you close the browser tab. Join does not use cookies.

7. Fonts

All fonts are hosted locally. No connection to external font providers is made.

8. Legal basis

Data is processed on the basis of your consent (Art. 6 (1) (a) GDPR), which you give by accepting this privacy policy during sign up.

9. Storage period

Data is stored until you ask us to delete it or until the project is discontinued.
